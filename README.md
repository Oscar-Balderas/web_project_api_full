# Around the U.S. — Full Stack

## Description

Around the U.S. is a full-stack web application that allows users to create and manage an interactive photo gallery.

Users can securely register, sign in, edit their profile information, update their avatar, upload image cards, like photos, and remove their own content.

The application was built with a React frontend and a RESTful backend developed using Node.js, Express, and MongoDB. Both services are deployed independently on Google Cloud.

This project demonstrates the implementation of authentication, database integration, API development, and modern frontend architecture.

- Secure JWT authorization
- Profile editing

- Responsive user interface
- RESTful API
- MongoDB database integration
- Independent frontend and backend deployment
